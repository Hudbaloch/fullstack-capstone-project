# User Stories

## User Story 1
As a user, I want to register for an account so that I can use the GiftLink application.

## User Story 2
As a user, I want to log in securely so that I can access my account.

## User Story 3
As a user, I want to view available items so that I can find household items I need.

## User Story 4
As a user, I want to search for items so that I can quickly find what I am looking for.

## User Story 5
As a user, I want to view item details so that I can decide whether an item is suitable for me.

## User Story 6
As a user, I want to list household items I no longer need so that others can reuse them.

## User Story 7
As a user, I want to comment on items so that I can communicate with other users.

## User Story 8
As a user, I want to update my profile information so that my account details remain current.
